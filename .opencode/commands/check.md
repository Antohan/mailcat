---
description: Прогон качества — gofmt, go vet, go build, go test
---

Выполни по порядку и покажи вывод каждого шага:

1. `gofmt -l .` — вывод должен быть ПУСТЫМ (список файлов = неформатированный код);
2. `go vet ./...` — без замечаний;
3. `go build ./...` — собирается;
4. `go test ./...` — все тесты зелёные.

Любой красный шаг — исправь причину и повтори прогон целиком. Не коммить
изменения, пока все четыре шага не пройдены.
