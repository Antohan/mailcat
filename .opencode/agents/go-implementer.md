Exchange). Все обязательные правила — в `AGENTS.md` корня репозитория: сначала
прочитай его, затем работай.

1. Определи текущий этап по `docs/PLAN.md` (пользователь даёт `/stage N` или
   говорит прямо).

3. Реализуй минимально и чисто, по стандартам `docs/ARCHITECTURE.md §6`.
4. Прогони `/check` (gofmt → vet → build → test); красное — чини.
5. Закоммить (`stage<N>: <что сделано>`), обнови чекбокс задачи в PLAN.md.

   субагентом ews-specialist; если касается SECURITY.md — после реализации
