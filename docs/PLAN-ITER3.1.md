# Итерация 3.1 — структурный редизайн по референсу

> Активный план (формат — `docs/PLAN-TEMPLATE.md`). Родительская итерация 3
> (`docs/PLAN-ITER3.md`) выполнена; этот план — доработка её визуального
> результата по структурному референсу пользователя (макет MailTUI,
> 21.11.2026). Золотые правила, SECURITY.md и токен-дисциплина AGENTS.md
> сохраняют силу.

## Не-цели этого плана (осознанно отложено)

- Цветовая палитра Catppuccin (Latte/Mocha) — после структуры, следующей
  итерацией; работаем на текущей светлой палитре;
- иконки (в т.ч. Nerd Font) — убраны (П.2а), не возвращаем;
- сниппет-строка через `item:Preview` — риск 500 на живом сервере (кейс
  `item:IsRead`); вернуться при желании отдельной задачей с smoke-тестом;
- сортировка и поиск — новые функции, не сейчас;
- write-операции (mark-as-read/delete) — отдельная будущая итерация, решения
  зафиксированы в обсуждении.

## Журнал решений (CHANGELOG.md) — обязательное правило итерации

После каждой завершённой задачи агент дописывает запись в НАЧАЛО
`CHANGELOG.md` (формат — см. записи итерации 3):

```markdown
## 2026-11-21 · iter31:V-1 · двухстрочные строки списка
- Сделано: <1–2 фразы>
- Решения: <нестандартный выбор и почему> (или «нет»)
- Отклонения от плана/золотых правил: <что и почему> (или «нет»)
```

- Одна запись на задачу (коммит), 3–5 строк.
- Отклонения от плана — только через журнал; существительные — записать и
  спросить пользователя. Молча менять план запрещено.

## Цель

Структура окна, панелей и объектов — как в референсе: двухстрочные строки
списка (точка непрочитанности + отправитель + время / тема), заголовок списка
со счётчиком и пагинацией, сайдбар с группами и футером статуса, верхний бар,
просмотр с шапкой-аватаром и секцией вложений, нижняя панель с кейкапами.
Визуальные задачи закрываются скриншотом до коммита.

## Задачи

Порядок выполнения — как пронумеровано (V-10 — мелкий баг, первым).

- [x] **V-10. Баг: огрызки угловых скобок вокруг маркеров ссылок**
      («в блоге`<[1]` host`>`»). Причина: в `internal/mail/links.go` (~91)
      регулярка автоссылок держит `<`/`>` отдельными группами, и при замене
      URL маркером `[N] host` скобки остаются. Fix: поглотить скобки в матче.
      Тест: строки с автолинками `<https://…>` и голыми URL — маркеры без
      мусора.
- [x] **V-1. Строки списка — двухстрочные по референсу**
      (`format.go`: `FormatMessageRow` → `FormatMessageListItem`;
      `mail.go` — таблица → `tview.List` с main/secondary или эквивалент)
      - строка 1: точка статуса (accent = непрочитан, muted = прочитан) +
        отправитель (жирный, если непрочитан) + время справа (паддинг по
        ширине панели);
      - строка 2: тема, обрезка многоточием;
      - маркер [ВНЕШН] — фиксированная ширина перед отправителем, панель не
        сдвигается (П.4г);
      - плотность: осознанный трейд-офф (~в 2.5 раза меньше писем на экране) —
        решение зафиксировано пользователем;
      - Sanitize + tview.Escape сохраняются; выделение/скролл без мерцания
        (инвариант UI-9/статус-бар).
- [x] **V-2. Заголовок списка: счётчик и пагинация**

## Definition of Done (итерация целиком)

- Структура соответствует референсу (проверка по чек-листу макета:
  двухстрочные строки, заголовок списка с пагинацией, сайдбар-футер,
  верхний бар, шапка просмотра с аватаром, секция вложений, кейкапы).
- Тело письма ≤90 колонок с центрированием; артефакт «`<[1] host>`» исчез.
- Панель списка не сдвигается при появлении [ВНЕШН].
- Скриншот каждой визуальной задачи приложен до коммита (правило итерации).
- Проверка в Terminal.app (256 цветов) и truecolor-терминале; resize
  100×30 → 220×60 без наложений и обрезок.
- Тесты зелёные; Sanitize/Escape и тесты-сторожа не ослаблены.
- CHANGELOG-запись на каждую задачу.

## Правила итерации

- Ветка — `dev`; merge в main — только `/release` после DoD и smoke.
- Одна сессия = одна задача: `/check` → коммит `iter31:V-N: <сделано>` →
  CHANGELOG → чекбокс → HANDOFF.
- **Правило визуальных задач**: скриншот до/после прикладывается к отчёту
  задачи; следующая визуальная задача не стартует без «ок» пользователя.
- Модели: Flash по умолчанию; флагман — по усмотрению на V-1 и V-5.
- Sanitize + tview.Escape не ослаблять; инварианты HANDOFF «Не трогать»
  (статус-бар UI-9 — особенно для V-7).
